# Orla Browser — Website Product Truth

Orla is a Windows desktop browser preview using Tauri and WebView2. It organizes tabs and references around project workspaces.

## Verified capabilities
- Workspaces and project-specific tabs
- Split view for two pages in one window
- Saved, searchable captures
- Session restoration and JSON session export
- Omnibox and searching open tabs
- Dockable developer tools through F12
- Loading compatible unpacked extensions, with WebView2 limitations
- Local storage for workspace, sessions and captures

## Shipping reality
- Preview available for Windows x64; not a stable release announcement
- Current distribution uses GitHub build artifacts and may require sign-in
- Configure ORLA_DOWNLOAD_URL when a permanent installer is published
- Website demo data are illustrative, not a screen recording

## No unsupported claims
Do not claim speed or memory benchmarks, zero tracking, universal extension support, cloud synchronization, Mac/Linux support, user counts or firm release dates.

## Visitor outcome
Understand why workspaces matter, try the demonstration, check compatibility, then download the Windows preview through the actual destination.
